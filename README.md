# dvwa-hardened-script
## Installation

> git clone https://github.com/cyberxploithausa/dvwa-hardened-script.git
> cd dvwa-hardened-script
> chmod +x *.sh

# Hardened Metasploitable 2
> sudo bash 1-hardened-metasploitable2.sh

# Un-Hardened Metasploitable 2
> sudo bash 2-un-hardened-metasploitable2.sh

# All in one script 
To use a single script that will hardened and un-hardened the box use

> sudo bash 3-all-in-one-manage-metasploitable2.sh --hardened
OR
> sudo bash 3-all-in-one-manage-metasploitable2.sh --vulnerable
